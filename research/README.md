# research/

Слой научных материалов. Здесь живут источники, гипотезы и свидетельства —
**отдельно от кода** (см. docs/ARCHITECTURE.md: DATA LAYER).

- `literature/` — научные статьи, заметки по источникам (S-номера из
  `docs/DATA_SOURCES.md`), ключевые цитаты.
- `datasets/` — описания и ссылки на данные (крупные файлы в git НЕ хранятся).
- `hypotheses/` — сформулированные проверяемые гипотезы (`HYP` по классификации
  `docs/RESEARCH.md`).
- `evidence/` — собранные наблюдения с указанием источника (source / DOI / PMID).

Формат записей — по правилам `docs/RESEARCH.md`.
