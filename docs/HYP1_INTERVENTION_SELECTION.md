## 1. Executive summary

Задача — выбрать пару для pilot проверки HYP-1
(`proteostasis/autophagy support × mitochondrial support`, исход — `fiber CSA day 14`,
тест — interaction `A×B`, обязательна стволозависимость).
Цель — не максимальный эффект, а **чистый тест interaction**.

Вывод анализа:

- TOP 3 A: `spermidine` / `intermittent low-dose rapamycin` (с оговоркой о регенерации) / `urolithin A` (с оговоркой о пересечении с осью B).
- TOP 3 B: `urolithin A` / `nicotinamide riboside (NR)` / `elamipretide (SS-31)` (запасной — `NMN`).
- TOP 3 пары: `spermidine × NR` / `spermidine × urolithin A` / `intermittent rapamycin × NR` (только с washout-дизайном).
- Preferred pair: **`spermidine × NR`** — наиболее комплементарная, мягкая, управляемая
  и практичная связка; confirmatory дозы/`δ`/`n` — только из pilot.
- Прямых данных «субпорог A×B + `CSA day 14` + stem-block в старой мышце» не найдено;
  ближайший отрицательный прецедент (`NR+PT` у пожилых, MuSC-рекрутмент без улучшения)
  не закрывает HYP-1 (другая связка, полные дозы, другая травма, без interaction-теста).
- Статус: `READY_FOR_PILOT_SELECTION` (выбор для pilot готов; confirmatory — только после pilot).

## 2. Search strategy

Источники — преимущественно 2020–2026, приоритет: peer-reviewed оригинальные опыты,
затем систематические обзоры/мета-анализы, затем авторитетные обзоры, препринты —
только с пометкой. Контекст поиска: `aged skeletal muscle`, `muscle regeneration`
(`cardiotoxin/CTX`, `fiber CSA`), `MuSC`/сателлиты, `autophagy`, `proteostasis`,
`mitochondrial function`, старые животные. Данные из другой ткани засчитываются
только как `Indirect`, прямым доказательством для старой мышцы не считаются.
Проверены: комбинации с `rapamycin`, `NAD`-ось, `autophagy + mitochondrial`,
`senolytics + regenerative`, multi-hallmark связки (§9).

## 5. Не путать механизмы (Direct / Indirect / Plausible)

- Direct: только опыты непосредственно в `aged skeletal muscle` (старые животные/пожилые люди,
  мышца, регенерация/`CSA`/сила/дыхание биоптата). Пример: `UA` — сила и мито-сигнатура
  у пожилых; `NR` — подъём `NAD+`-метаболома в мышце пожилых; `rapamycin` — ломка и
  спасение регенерации в зависимости от режима (оба — direct, с разным знаком).
- Indirect: другие ткани/модели (печень, иммунитет `UA 2025`, дрозофила/червь,
  молодые животные, клеточные линии). Не засчитывается как доказательство для мышцы.
- Mechanistically plausible: связь логична (`mTOR→аутофагия`, `NAD+→SIRT→мито`),
  но прямых мышечных данных мало (`trehalose/beclin-1`, часть `SS-31→MuSC`).
- Категории не смешиваются: в таблицах §§3–4 колонка качества опирается только
  на Direct для мышцы; остальное — понижающие/уточняющие пометки.

## 6. Исключённые / пониженные кандидаты (§5 постановки)

- Хронический/ежедневный `rapamycin` в полных дозах — исключён как режим
  (ломает регенерацию, `PMID 19794149`; давит синтез белка при стимуле).
  Остаётся только `intermittent low-dose` с washout и мониторингом глюкозы/инфекций.
- `Caloric restriction` / голодание как A — исключены (сильный systemic/весовой эффект,
  неотделим от регенерации; нарушает чистоту `A×B`).
- Прямые анаболики/андрогены/`IGF`-агонисты — исключены (гипертрофия без регенерации,
  пролиферация независимо от `MuSC`, потолок CSA).
- `Urolithin A` одновременно в A и B — запрещено (одно вещество не может быть
  обеими осями; иначе interaction неинтерпретируем). `UA` — только одна ось в паре.
- `NMN` vs `NR` одновременно — избыточно (одна `NAD+`-ось; в паре только один).
- Сенолитики (`D+Q`/навитоклакс) как A/B — исключены из этой связки
  (другая ось — ниша/сенесценция; в HYP-1 ниша — follow-up, а в молодом ремонте
  сенолитики даже ухудшали картину, `PMID 42314772`; смешивать нельзя).

## 7. Subthreshold requirement

HYP-1 требует mild/subthreshold: каждая моно-рука — небольшой измеримый эффект
или ноль, значимый выигрыш ожидается только от `A+B` через interaction.
Поэтому:

- Полнодозовые режимы с известным моно-эффектом (например `UA 1000 мг` с моно-выигрышем
  силы) для confirmatory не годятся без снижения — иначе это тест «сильное + слабое»,
  а не interaction субпорогов.
- Конкретные числа — только `requires pilot dose-ranging` (титрование `n=4–6`/доза
  до незначимости моно-плеч для `CSA` при сохранности target engagement по вторичкам).
- Отрицательный прецедент `NR+PT` (полные дозы, ноль по `MuSC`) парадоксально полезен:
  он задаёт верхнюю границу «полная доза ≠ гарантия», поэтому pilot идёт снизу вверх.

## 8. Pairwise analysis (A×B)

Проверены: фармакологические пересечения, общая токсичность, общий метаболизм,
общие downstream-пути, маскировка, потолок, антагонизм. Биологическая синергия
отделяется от фармакологического взаимодействия/экспозиции/токсичности.

- `spermidine × NR`: пересечений по CYP/экспозиции не описано (нутрицевтик + витамин B3);
  downstream различны (объёмная аутофагия/лизосома vs `NAD+`/окислительное фосфорилирование),
  сходятся на `MuSC`-энергетике/протеостазе — это и есть проверяемая связка, а не дефект.
  Потолок маловероятен при субпорогах; антагонизм не описан. Чистота высокая.
- `spermidine × urolithin A`: оба трогают аутофагию/митофагию (объёмная vs селективная) —
  частичный downstream-overlap; выигрыш: оба с прямыми мышечными данными и безопасностью;
  риск: interaction частично неинтерпретируем (чья митофагия сработала). Требуется
  разделение вторичками (общие `LC3/p62` vs селективные `PINK1-Parkin`/дыхание).
- `intermittent rapamycin × NR`: механистически красиво (`mTOR↓→аутофагия` + `NAD+`),
  прецедент `CR + rapamycin` аддитивен (`2022`), но для исхода регенерации —
  конфликт: `rapamycin` давит раннюю регенерацию; без washout-окна и мониторинга
  глюкозы/инфекций пара нечистая. Допустима только как третья, с жёсткими условиями.
- `rapamycin × urolithin A`: не рекомендована (двойное давление на аутофагию/митофагию
  + регенерационный риск `rapamycin` + overlap `UA`; интерпретация interaction
  почти невозможна).
- `NR × NMN` / `NR × SS-31` как `A×B`: запрещено/бессмысленно как тест HYP-1
  (одна ось дважды либо без протеостазного плеча).

## 9. Stem dependence для пар

Реалистичность проверки `A+B → регенерация → MuSC-зависимо`:
`CTX TA` + `fiber CSA day 14` + `Pax7`-гистология + ex vivo `MuSC` (колонии/слияние) +
доля de novo волокон + stem-block плечо — достаточный набор; весь список биомаркеров
в обязательные endpoints не превращается (см. preregistration §7 вторичек).

- `spermidine × NR`: высокая проверяемость (оба плеча имеют `MuSC`-механику:
  аутофагия для кваiescence/активации; `NAD+/SIRT1` для OXPHOS-генов `MuSC`).
- `spermidine × UA`: средняя (оба влияют на `MuSC`, но разделить «чья» сложно;
  stem-block покажет необходимость стволовых, но не разделит оси — нужны селективные вторички).
- `rapamycin × NR`: низкая без washout (`rapamycin` сам давит `MuSC`-пролиферацию/
  ранние волокна; stem-block на фоне ингибитора трудно читать).

## 10. Особая проверка: не проверена ли HYP-1 раньше под другим названием

- `NR + pterostilbene` у пожилых после травмы (`NCT03754842`, `PMC9675477`):
  ближайший дизайн (пожилые + травма + `MuSC`-рекрутмент), результат отрицательный.
  Но это НЕ HYP-1: нет протеостаз-праймера, дозы полные (не субпорог), травма —
  электростимуляция+эксцентрика (не `CTX`), нет interaction-теста субпорогов.
  Вывод: не закрывает, задаёт границу ожиданий. Скрывать запрещено — зафиксировано.
- `CR + rapamycin` в геронтологической мышце: аддитивность, разные профили (`2022`) —
  поддерживает саму идею комбинаций, но оси другие (энергетика whole-body + `mTOR`).
- `OSK + FOXO4-DRI` (мухи), `SenoVax + pMSC` (печень/ускоренное старение) —
  синергии на других осях; нашу связку не тестируют.
- `trametinib + rapamycin` (мыши, `2025`): аддитивность, эталон «комбинация лучше
  без синергии» — именно поэтому HYP-1 требует interaction, а не «лучше одиночек».
- Секвенированный `NAD+ → rapamycin → сенолитики` (препринт `2025.12.0724`) —
  гипотеза о порядке, не рандомизированное доказательство; вес низкий.
- Итог: точной копии (субпорог `A×B` + `CSA day 14` + stem-block в старой мышце)
  не найдено. HYP-1 в узкой формулировке ранее не проверена.

### TOP 3 A candidates

1. `spermidine` — мягкий пероральный праймер аутофагии; прямые мышечные данные есть,
   сателлиты активирует, переносимость хорошая, окно субпорога широкое.
2. `intermittent low-dose rapamycin` — только с washout и оговорками; сильный механизм,
   но регенерационный и метаболический багаж; без строгих условий — не брать.
3. `urolithin A` (как A) — сильные мышечные данные и безопасность, но только если B —
   не митофагия (иначе overlap); в паре с `NR` не использовать как A.

### TOP 3 B candidates

1. `urolithin A` (как B) — сильнейшие прямые мышечные мито-данные + безопасность;
   ограничение — не спаривать с митофагическим A.
2. `NR` — лучший `MuSC`-привязанный кандидат с человеческими данными (включая честный
   ноль `Jensen 2022`); безопасность хорошая; субпорог управляем.
3. `elamipretide (SS-31)` — запасной с другой мито-механикой; данных по `MuSC/CSA` меньше,
   доступность хуже. (`NMN` — четвёртый, почти дубль `NR`.)

### TOP 3 A×B pairs

1. **`spermidine × NR`** — почему: комплементарность (объёмная аутофагия + `NAD+`-энергетика),
   оба мягкие/пероральные, пересечений нет, окно субпорога широкое.
   Известно: каждый по отдельности мышцу трогает, вместе в `CSA day 14` старых не тестированы.
   Неизвестно: дозы субпорога, `δ`, `n`. Главный confounder: системный метаболизм (еда/масса) —
   лечится `pair-feeding`/ковариатой + ex vivo `MuSC`. Для HYP-1 подходит лучше всех.
2. **`spermidine × urolithin A`** — почему: оба с прямыми мышечными данными и безопасностью.
   Известно: моно-эффекты есть. Неизвестно: разделимость вкладов (общий аутофагический тракт).
   Confounder: overlap downstream. Подходит как вторая (нужны селективные вторички).
3. **`intermittent rapamycin × NR`** — почему: сильнейшая механистическая пара + прецедент
   аддитивности `CR+RM`. Известно: регенерационный риск `rapamycin`. Неизвестно: окно без
   подавления регенерации. Confounder: глюкоза/иммунитет/ранние волокна. Подходит только
   с washout и жёстким мониторингом; иначе — нет.

Основание: максимальная комплементарность при минимальных confounders, оба —

нетолерантность/отсутствие target engagement/невозможность субпорога — пара меняется
через новую пред-регистрацию, а не подгонкой. `NO PREFERRED PAIR YET` не выбран,
потому что данных для pilot-выбора достаточно, а для confirmatory — по правилам
и не требуется сейчас (см. §15).

## 13. Pilot concept (только концептуально, без операционного протокола)

Objective (не доказать HYP-1): tolerability; subthreshold range `A`/`B`
(моно-плечи незначимы для `CSA`); оценка variance (межживотная SD для §10 prereg);
параметры для power analysis; подтверждение engagement осей
(аутофагический поток; `NAD+`-метаболом/дыхание) без превращения вторичек в primary.

## 14. Confirmatory prerequisites (фиксируются после pilot)

`exact A`, `exact B`, `dose`, `schedule` (включая washout-решения),
`δ` (минимум interaction в единицах `CSA`), `sample size`,
`inclusion/exclusion`, `statistical model` (§7 preregistration).
После фиксации — подпись preregistration; изменения по результатам запрещены.

## 15. Confounders (таблица)

| Confounder | Как проявится | Как отличить |
|---|---|---|
| hypertrophy | рост `CSA` без новых волокон | доля de novo волокон, центральные ядра, число волокон/ядер, сила на волокно |
| metabolic rescue | функция лучше без `MuSC`-вклада | stem-block + ex vivo `MuSC` вне системного контекста |
| toxicity | гибель/выбывание, «улучшение» среднего | мониторинг токсичности, учёт потерь, распределение `CSA`, фиброз |
| body-weight effect | системное улучшение с массой/едой | корм/масса, `pair-feeding`/ковариата |
| niche remodeling | регенерация меняется без прямого `MuSC`-эффекта препаратов | маркеры ниши/сенесценции (`p16/SA-β-gal/SASP`) во всех группах |
| pharmacological interaction | изменение экспозиции/покрытия, а не биология | разнесённые downstream-вторички осей; проверка перекрытия путей (§8) |

## 16. Evidence grading (ключевые утверждения)

- Аутофагия обязательна для `MuSC` (кваiescence/активация) — Strong direct evidence
  (генетика + старая мышца; `Tang & Rando 2014`; `Garcia-Prat 2016` + обзоры 2021–2026).
- `Spermidine` реактивирует аутофагию в мышце — Moderate direct evidence
  (мышечные модели; часть данных до 2020 — grade не завышен).
- `NR` поднимает `NAD+`-метаболом мышцы пожилых — Moderate direct evidence
  (`PMCID PMC6702140`); улучшение регенерации/силы у пожилых — Weak/Negative
  (`PMC9675477`; мета-анализ `JCSM 2025` неубедителен).
- `UA` улучшает мито-сигнатуру/силу — Moderate direct evidence
  (`PMID 32694802`; `Cell Rep Med 2022`; `JAMA Netw Open 2022`); `CSA day 14` старых —
  Unknown (клиника мерила другое).
- Ежедневный `rapamycin` ломает острую регенерацию — Strong direct evidence
  (`PMID 19794149`); прерывистый режим совместим с гипертрофией — Moderate direct
  (`PMCID PMC12507417`); перенос на старую `CTX`-модель — Unknown без pilot.
- Субпороговая `A×B` супераддитивность с `CSA day 14` + stem-block — Unknown
  (точной копии не найдено); правдоподобие — Mechanistic plausibility + Indirect.
- Grade не повышается «за логичность»: где данных нет — стоит `Unknown`.

## 17. Limitations

- Часть опорных данных старше окна 2020–2026 (честно помечены; вес снижен).
- Человеческие `NR`-данные по регенерации — отрицательные; перенос мыши→человек не утверждается.
- `Rapamycin`-ветка держится на режиме/окне; без pilot — только третья пара.
- `SS-31`/`NMN` — запасные с более тонкой базой именно под `CSA/MuSC`.
- Дозы, `δ`, `n` — только из pilot; любые числа сейчас были бы выдумкой.

## 20. Scientific rules — соблюдение

- Синергия без interaction evidence не утверждается (требуется `τ_AB > δ` + CI + stem-block).
- Animal evidence не выдаётся за human evidence (перенос запрещён; `Jensen 2022` ноль зафиксирован).
- Plausibility не выдаётся за confirmation (где нет данных — `Unknown`).
- Дозировки/`n` не выдуманы (везде `requires pilot dose-ranging`).
- HYP-1 под литературу не менялась (формулировка Stage 11 сохранена).
- Computational stage не создаётся; production model не тронута; simulated wet-lab нет;
  HYP-1 не объявлена подтверждённой. Противоречий HYP-1 в литературе не найдено;
  где данных мало — стоит `INSUFFICIENT EVIDENCE` для confirmatory (но не для pilot-выбора).
