# LONGEVITY.md — Lifespan, healthspan, rejuvenation, immortality

Этот документ фиксирует **понятия**, используемые в проекте, и требования к их
количественному определению. Понятия **не смешиваются**.

## 1. Определения

| Термин | Определение | Как измеряется в модели |
|---|---|---|
| **LIFESPAN** | Сколько времени организм существует (до утраты жизнеспособности системы) | время до терминального состояния; в модели — момент, когда система не может поддерживать себя |
| **HEALTHSPAN** | Сколько времени организм сохраняет нормальную функцию | время, пока все ключевые метрики (см. CELLULAR_AGING.md) в заданных пределах |
| **REJUVENATION** | Возвращение отдельных систем в более молодое функциональное состояние | сравнение набора метрик до/после вмешательства |
| **IMMORTALITY** | Способность сохранять необходимую функциональность неопределённо долго | **предельная исследовательская гипотеза**, а не цель по умолчанию |

## 2. Принцип

- Симулятор **не** оптимизируется для максимизации lifespan.
- Результаты симуляции сами показывают, какие механизмы ограничивают
  жизнеспособность системы.
- Immortality — один из возможных **исходов** исследования, требующий доказательства
  устойчивости конфигурации в долгосрочной перспективе, а не допущение.

## 3. Требования к измеримости

Чтобы термин имел смысл в вычислениях, нужны:

1. **Явный набор метрик** (cell count, functional markers, ...).
2. **Порог "нормальной функции"** для healthspan (например: параметры в пределах
   X% от базовых значений).
3. **Порог "жизнеспособности"** для lifespan (система не может поддерживать себя;
   популяция ниже минимального порога и т.д.).
4. **Протокол сравнения** для rejuvenation: одна и та же симуляция (seed, конфиг),
   без/с вмешательством.

Без порогов никакая симуляция не может отличить «старость» от «смерти».

## 4. Соотношение понятий (иерархия)

```
IMMORTALITY требует продлить healthspan неограниченно,
healthspan не может превысить lifespan,
lifespan ≥ healthspan (по определению).
```

Логические связи:

- `LIFESPAN >= HEALTHSPAN` — всегда.
- `REJUVENATION` — операция сравнения, потенциально увеличивает оба.
- `IMMORTALITY` требует одновременно:
  - отсутствие терминального отказа (lifespan = ∞);
  - поддержание метрик выше порога (healthspan = ∞);
  - устойчивость к шуму и стохастичности (повторные запуски с разными seed).

## 5. Что НЕ входит в понятия

- Клинические рекомендации для людей — симуляция не является медицинской моделью.
- Моральные/философские оценки «ценности» долголетия.
- Утверждение, что продление достижимо — без доказательства в результатах.
