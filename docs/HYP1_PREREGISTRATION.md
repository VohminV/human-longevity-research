## 1. FORMAL HYPOTHESIS

Обозначения факторов (бинарные, `0/1`):

- `A` — Intervention A (поддержка протеостаза/аутофагии; конкретный агент
  выбирается отдельно по литературе, безопасности и pilot data, здесь без названия дозы).
- `B` — Intervention B (поддержка митохондриальной энергетики; аналогично без дозы).
- `S` — stem-block condition (`0` = интактные стволовые, `1` = заблокирован
  стволовый вклад; отдельное mechanistic validation плечо, см. §4–5).

Primary estimand — средний каузальный interaction-эффект на уровне животного:

```text
τ_AB = E[Y | A=1, B=1] − E[Y | A=1, B=0] − E[Y | A=0, B=1] + E[Y | A=0, B=0]
```

где `Y` — primary endpoint из §3 (средний CSA регенерированных волокон животного).

Формальные гипотезы для interaction (нуль — аддитивность, см. §2):

```text
H0: τ_AB ≤ 0   (нет супераддитивности: ноль, аддитивность в пределах нуля, или антагонизм)
H1: τ_AB > δ  (супераддитивность больше заранее зафиксированного минимума δ > 0)
```

Здесь `δ` — минимально биологически значимый interaction (см. §9; численно
фиксируется из pilot/prior до preregistration, не придумывается здесь).

Primary endpoint: `muscle fiber CSA at day 14` (см. §3).
Interaction term `A×B`: коэффициент `βAB` в модели §2, оценка `τ_AB`.
Роль stem-block: отдельный тест необходимости стволового звена
(`S=1` должен убрать/существенно уменьшить `τ_AB`; см. §5).

Поддержкой HYP-1 считается **только** конъюнкция из §8
(супераддитивность + минимум эффекта + animal-level + стволозависимость +
отсутствие токсического объяснения). Заранее различаем 4 исхода:

1. отсутствие эффекта — `A`, `B`, `A+B` неотличимы от контроля;
2. аддитивный эффект — `A+B ≈ A + B`, `τ_AB ≈ 0`;
3. антагонизм — `A+B` хуже суммы (`τ_AB < 0`);
4. супер-аддитивный эффект — `τ_AB > δ` с CI выше нуля (только он + §5 = поддержка).

Сравнение `(A+B) > A` или `(A+B) > B` синергией **не считается**.

## 2. ADDITIVE NULL

Базовая модель для `2×2` ядра (`Control/A/B/A+B`):

```text
Y = β0 + βA·A + βB·B + βAB·A×B + ε
```

- `β0` — средний исход контроля (`A=0, B=0`).
- `βA` — средний прирост от `A` при `B=0`.
- `βB` — средний прирост от `B` при `A=0`.
- `βAB` — отклонение комбинированного эффекта от суммы одиночных,
  то есть `τ_AB`. При аддитивности `βAB = 0`; при синергии `βAB > 0`;
  при антагонизме `βAB < 0`.
- Для поддержки HYP-1 нужны одновременно: `βAB > 0`, оценка выше минимума
  `δ` (§9) и интервал, исключающий нуль по заранее зафиксированному правилу (§8).

Почему сравнения средних недостаточно: пары `(A+B vs Control)`,
`(A+B vs A)`, `(A+B vs B)` смешивают главные эффекты и взаимодействие.
Комбинация может быть «лучше каждой одиночки» при чисто аддитивном
(и даже субаддитивном) сложении. Только `interaction contrast`
`[(A+B) − B] − [A − Control]` отделяет синергию от суммы.
Для долевых/ограниченных исходов (если primary переформулируют в долю)
аналог — `Bliss independence null`; здесь primary непрерывен (площадь),
поэтому линейный аддитивный нуль — дефолт; усложнять без необходимости запрещено.

## 3. PRIMARY ENDPOINT

```text
Primary endpoint = muscle fiber cross-sectional area (CSA) at day 14
(среднее по регенерированным волокнам животного; см. §7 про unit of analysis).
```

Запрещён post-hoc перевод primary на: силу, митохондриальные маркеры,
маркеры аутофагии, число `MuSC`, маркеры регенерации, выживаемость, массу тела.
Они — только secondary/exploratory (см. §6).

Primary должен быть один, потому что: один главный тест = один заранее
зафиксированный критерий успеха/фальсификации; несколько «главных» исходов
позволяют выбрать выигравший задним числом и ломают логику §8.
Вторички служат цепочке механизма и разоблачению альтернатив, а не запасными
воротами для победы.

## 4. EXPERIMENTAL GROUP STRUCTURE

Ядро factorial (`2×2`, для строгого interaction-анализа):

- `Control` (`A=0, B=0`)
- `A` (`A=1, B=0`)
- `B` (`A=0, B=1`)
- `A+B` (`A=1, B=1`)

Отдельное mechanistic плечо (не часть `2×2` нуля):

- `A+B + stem-block` (`S=1`): проверка необходимости стволового звена (см. §5).

Конкретные вещества и дозы не выдумываются. `Intervention A` и `Intervention B`
обозначают классы (протеостаз-праймер; мито-энергетическая поддержка),
а выбор агента, дозы, схемы и окна обосновывается отдельно по литературе,
безопасности и pilot data (§12) и фиксируется до confirmatory фазы.

## 5. STEM DEPENDENCE

«Stem-dependent regeneration» здесь означает: прирост CSA при `A+B`
идёт через активацию/пролиферацию/слияние сателлитных стволовых клеток
(`Pax7+` пул, `MyoD`/слияние ex vivo, доля de novo волокон с центральными
ядрами/эмбриональным миозином), а не через отёк, выжившие волокна или
гипертрофию без новых клеток. Определение фиксируется до данных и после
не переопределяется.

- Поддерживают HYP-1: `τ_AB > δ` по CSA **и** согласие вторичек
  (`MuSC` активны, протеасома/дыхание двинулись) **и** stem-block убирает
  или существенно уменьшает выигрыш (заранее зафиксированный порог редукции,
  например `≥50%` interaction-эффекта снимается; число фиксируется в preregistration
  из pilot/prior, здесь не выдумывается).
- Ослабляют HYP-1: `τ_AB > 0`, но CI широк/граничен, или вторички расходятся
  (CSA вырос без `MuSC`/молекулы), или stem-block снижает частично, но ниже порога.
- Фальсифицируют HYP-1: `τ_AB ≤ 0` по правилу §8; либо супераддитивность есть,
  но stem-block её **не** устраняет/не уменьшает — тогда исходная формулировка
  со словом «стволозависимую» считается неподтверждённой/фальсифицированной,
  даже если цифры CSA красивые. Переопределять «stem-dependent» после результата запрещено.

## 6. ALTERNATIVE EXPLANATIONS

Для каждой — predicted pattern, measurement, interpretation.
Вторички не повышаются до primary.

1. additive effect:
   pattern — `A+B ≈ A + B`, `τ_AB ≈ 0`;
   measurement — interaction contrast + CI (§7);
   interpretation — нет синергии → HYP-1 отвергнута (даже если `A+B` лучше всех).

2. metabolic effect independent of stem cells:
   pattern — выигрыш коррелирует с едой/массой/гликемией, ex vivo `MuSC` без эффекта;
   measurement — корм/масса, `pair-feeding` при сдвиге, ex vivo колонии/деление;
   interpretation — выигрыш системный, не стволовой → HYP-1 отвергнута.

3. toxicity/selection:
   pattern — среднее CSA выросло, а число волокон/ядер упало, фиброз/гибель выросли;
   measurement — число волокон и ядер, гибель/фиброз, распределение CSA, сила на волокно;
   interpretation — артефакт отбора → HYP-1 отвергнута.

4. niche remodeling (разгрузка без протеостаза/мито):
   pattern — падает только сенесцентная нагрузка, протеасома/дыхание стоят;
   measurement — `p16/SA-β-gal/SASP` панель во всех 4 группах + корреляция с CSA;
   interpretation — сработала ниша, а не связка → исходная HYP-1 отвергнута.

5. hypertrophy rather than regeneration:
   pattern — CSA вырос без de novo волокон/`MuSC`-вклада;
   measurement — stem-block + `Pax7`-линия + доля de novo волокон;
   interpretation — гипертрофия/отёк → HYP-1 отвергнута.

## 7. STATISTICAL ANALYSIS PLAN (до данных)

- Unit of analysis: животное (не волокно). Все волокна одного животного —
  повторные измерения, а не независимые `n`.
- Anti-pseudoreplication: основной вариант — animal-level summary
  (средний CSA животного) + линейная модель `2×2` с interaction;
  альтернатива — иерархическая (mixed) модель `волокна в животных`
  со случайным intercept животного; выбор фиксируется в preregistration,
  оба варианта не прогоняются с выбором лучшего.
- Fixed effects: `A`, `B`, `A×B` (ядро); отдельно `S` и `S×(A×B)`-контраст
  для stem-block плеча (механистический, не часть главного нуля).
- Ковариаты (пред-фиксированные, мало): пол/batch партии травмы/исходная масса;
  без data-driven отбора ковариат.
- Intervals: двусторонний `95%` CI для `τ_AB` + односторонний interaction-тест
  на уровне `α = 0.05` (или `0.025` при обосновании; фиксируется заранее);
  рапортуются оценка, CI, `p` для interaction и стандартизованный эффект.
- Significance threshold: фиксируется до данных; порог минимума `δ` — отдельно (§9).
- Multiple testing: вторички — с поправкой (например `Holm`/`FDR`, метод фиксируется)
  и ярлыком exploratory; провал/успех HYP-1 решают только primary + §8.
- Assumptions/diagnostics: проверка остатков/гетероскедастичности пред-описанным
  способом; трансформации/робастные SE — только если пред-описаны, иначе sensitivity.

## 8. FALSIFICATION RULE (жёсткое)

HYP-1 получает поддержку, только если выполнены **все**:

1. `βAB > 0` (оценка interaction положительна);
2. оценка `≥ δ` (минимум из §9, зафиксирован из pilot/prior);
3. CI исключает отсутствие interaction по заранее зафиксированному правилу
   (например нижняя граница `95%` CI `> 0`; правило фиксируется, не подбирается);
4. результат на уровне животных (animal-level summary или иерархическая модель;
   significance только на волокнах без учёта животных — недействительна);
5. стволозависимость подтверждена (§5: stem-block снимает заранее зафиксированную долю);
6. нет токсического/селекционного объяснения (§6.3: число волокон/ядер, фиброз,
   распределение CSA не указывают на артефакт).

HYP-1 считается фальсифицированной, если выполнено **любое**:

- `βAB ≤ 0`;
- interaction неотличим от нуля по зафиксированному критерию;
- только аддитивность (`A+B ≈ A + B`);
- эффект есть, но от стволовых не зависит;
- эффект объясняется альтернативой из §6.

Различение: `p > 0.05` само по себе — это `failure to detect`
(недостаточно доказательств), а не `evidence against`.
Доказательством против считаются: CI, накрывающий нуль при достаточной
мощности **и** исключающий `δ`, либо выполнение любого пункта фальсификации выше.
Формулировка «p > 0.05 = доказательство отсутствия эффекта» запрещена.

## 9. EFFECT SIZE

- Минимум `δ`: заранее фиксированный interaction-эффект в единицах CSA
  (например мкм² среднего CSA животного; шкала фиксируется с протоколом гистологии).
- Рапорт: оценка `τ_AB`, CI в единицах CSA + стандартизованный эффект
  (например `Cohen d` для interaction) как secondary metric.
- Честная оговорка: величина `δ` из computational model не выводится
  (модель абстрактна, единицы условны). Поэтому:

```text
effect size must be fixed from pilot data or prior literature before preregistration
```

Число здесь не выдумывается. Без зафиксированного `δ` confirmatory фаза
не начинается (см. §12, статус `NOT_READY_FOR_PILOT`→ pilot сначала).

## 10. POWER / SAMPLE SIZE

Число животных здесь не выдумывается. Для расчёта нужны:

- expected variance (межживотная SD среднего CSA; из pilot/prior);
- expected interaction effect (оценка `τ_AB`, не главных эффектов);
- `alpha` (из §7);
- desired power (обычно `0.8`; фиксируется);
- expected attrition (потери/технический брак + запас).

Подход: мощность для interaction-теста `2×2` (симуляцией или формулой
для factorial interaction с animal-level SD; метод и софт фиксируются
в preregistration после pilot). Формула/скрипт прикладываются к регистрации.
Если pilot-оценок нет — прямо фиксируется: корректный `n` определить нельзя,
сначала pilot (§12).

## 11. RANDOMIZATION / BLINDING

Preregistration-ready требования (без выдумывания лабораторных деталей):

- random allocation в `Control/A/B/A+B` (+ stem-block плечо) со стратификацией
  (пол/помёт/batch), метод рандомизации фиксируется;
- blinded outcome assessment для гистологии CSA и силы (кто слеп, когда раскрытие);
- predefined inclusion/exclusion (возраст/масса/здоровье на входе, качество травмы,
  технические критерии среза) — список фиксируется до данных;
- handling of missing animals (учёт потерь, `intention-to-treat`-подобное правило
  для животных + sensitivity без выбывших; правило фиксируется);
- handling of technical failures (неудачная травма/срез — пред-определённые
  технические критерии, слепые к группе);
- no post-hoc removal based on treatment outcome (удаление по исходу запрещено;
  любое удаление — по пред-критериям и с отчётом).

## 12. PILOT VS CONFIRMATORY EXPERIMENT

### Pilot (разведка, не проверка HYP-1)

Цели: подобрать subthreshold range `A`/`B` (поодиночке незначимы для CSA),
оценить variance, проверить tolerability/токсичность, выбрать дозы и `n`-рамку.
Pilot не используется для правки гипотезы после подглядывания:
смена доз/исхода/модели после просмотра pilot-эффектов — только как новый
пред-регистрированный план, а не «уточнение».

### Confirmatory experiment (проверка)

После фиксации (дозы, primary endpoint, модель §7, критерии §8, `δ` из §9,
критерии исключения, `n` из §10) параметры не меняются по результатам.
Любое отклонение — протоколное нарушение с отчётом, а не «улучшение дизайна».

## 13. WET-LAB SAFETY / ETHICS

Без детальной процедуры содержания/хирургии. Фиксируется, что опыт на животных требует:

- institutional ethical approval до старта;
- соответствия применимым animal welfare regulations;
- заранее определённых humane endpoints;
- trained personnel;
- appropriate veterinary oversight.

Без одобрения — статус `NOT_READY_FOR_PILOT`.

## 14. COMPUTATIONAL → BIOLOGICAL TRACEABILITY

```text
computational observation (9/9b/10/10.5: singles mute, top distributed, partial accounting 14.34%)
→ candidate biological hypothesis (Stage 11 HYP-1: subthreshold A×B super-additivity, stem-dependent)
→ pre-registered prediction (этот документ: τ_AB > δ + stem-block + §8)
→ wet-lab test (pilot → confirmatory, вне этого документа)
→ falsification/support (по §8, без переопределений)
```

Обязательно:

**Computational result does not count as biological evidence for HYP-1.**

Модель мотивировала гипотезу (`computational result motivated`),
но доказательством служит только живой эксперимент.

## 15. NOVELTY

Осторожно, без слов про открытие механизма. HYP-1 — это:

```text
testable synthesis / narrow empirical hypothesis
```

а не established discovery. Похожие комбинации в литературе есть (см. §17),
но узкая связка (субпороговые дозы + пред-зарегистрированный interaction-null +
стволозависимый `fiber CSA` в старой мышце) в таком виде не найдена.
Запрещены формулировки «we discovered a new biological mechanism» и
«the model predicts a previously unknown synergy».

## 16. SUCCESS / FAILURE MATRIX

Статистически явная версия (primary — CSA животного; stem-block — отдельно):

| Result | Statistical pattern | Interpretation | HYP-1 status |
|---|---|---|---|
| No effect | `A≈B≈A+B≈Control`, CI `τ_AB` накрывает нуль и исключает `δ` при достаточной мощности | нет эффекта | falsified (для этих доз/системы) / inconclusive только при явной недомощности по пред-критерию |
| Additive | `A+B ≈ A + B`, `τ_AB ≈ 0`, CI вокруг нуля | сумма без взаимодействия | reject |
| Super-additive + stem-dependent | `τ_AB > δ`, CI выше нуля + вторички по цепочке + stem-block снимает эффект | предсказанный результат | support |
| Super-additive but stem-independent | `τ_AB > δ`, но stem-block не меняет | другой механизм | reject original HYP-1 |
| Antagonism | `τ_AB < 0` (CI ниже нуля) | `A+B` хуже суммы | reject |
| Toxicity/selection explains | CSA вырос при падении числа волокон/ядер, фиброз/гибель | артефакт | reject |

Строка «no detectable effect» читается только вместе с CI и мощностью:
широкий CI, накрывающий и нуль, и `δ` = `inconclusive (underpowered)`,
а не поддержка и не строгое опровержение; узкий CI вокруг нуля,
исключающий `δ` = доказательство против заявленного минимума.

  с центральными ядрами, `10–14` восстановление структур, `28` почти полное
  (обзор CTX-регенерации, `PMC9657523`).
- `MuSC`/сателлиты необходимы для регенерации; старость снижает пул и функцию;
  пространственно-временная координация с иммунными/`FAP` (обзор `2024`,
  `Inflammation and Regeneration`, DOI `10.1186/s41232-024-00354-1`).
- Сенолитики в молодой регенерирующей мышце: `D+Q` не улучшил силу/`CSA`
  (`PMID 42314772`, 2026) — предостережение: контекст (возраст/нагрузка) решает;
  наш дизайн — старая мышца + субпороговые дозы, прямое перенесение запрещено.
- Комбинации геропротекторов: чаще аддитивны — `trametinib + rapamycin`
  аддитивны у мышей обоих полов (`PMID 40437307`, `PMCID PMC12270913`,
  `Nat Aging 2025`); дрозофила `rapamycin + trametinib + lithium` аддитивны
  до `48%` медианы (обзор `Aging 206078`); `rapamycin + acarbose + phenylbutyrate`
  коктейль сильнее одиночек за 3 месяца (`Sci Rep 2022`, DOI
  `10.1038/s41598-022-11229-1`) — но без строгого synergy-теста.
- Синергия возможна, но не правило: `OSK + FOXO4-DRI` сенолитик синергичны
  у дрозофилы (обзор `Aging 206078`); `SenoVax + pMSC` синергичны
  (печень/ускоренное старение, `J Transl Med 2026`) — другие оси/ткани.
- `NAD+`/митофагия/аутофагия и протеостаз: `NMN/NR + резвератрол/птеростильбен/
  флавоноиды` обсуждаются как синергетические для `NAD+` (обзор `PMC9861325`);
  `PASS GERO` подтверждает полифармакологию (`rapamycin→mTOR/аутофагия`,
  `NR→NAD+/SIRT1/мито`), но это in silico, не доказательство (`PMC12470084`);
  секвенированный `NAD+ → rapamycin → сенолитики` протокол — препринт с гипотезой
  о порядке, не рандомизированное доказательство (`Preprints 2025.12.0724`).
- Клинические геропротекторы (`rapamycin` как `geroprotecTOR`, `RAP-PROTECT`,
  `PEARL`, `EVERLAST`; `PMC10643772`): дозы/sex/ткань-специфичность и взаимодействие
  с образом жизни неизвестны — ещё один аргумент за pilot, а не за выдуманные дозы.

Итог: HYP-1 не опровергнута; прямых опытов с такой же связкой
(субпорог `A×B` + `fiber CSA day 14` + stem-block в старой мышце) не найдено;
похожие комбинации существуют → классификация synthesis; более сильной готовой
формулировки с тем же фальсификатором не найдено.

## 18. NO NEW COMPUTATIONAL STAGE

Не создаются: Stage 12, новые механизмы, новый поиск, `RL`, оптимизация,
новые драйверы, новые entropy-переменные, новые скоринги.
Если модель не обосновывает какой-то wet-lab параметр (дозы, `δ`, `n`) —
это limitation, зафиксированная в §§9–10, а не повод новым моделированием.

## 19. FINAL DECISION

Чеклист готовности:

- HYP-1 формально определена (§1) — да.
- Additive null определён (§2) — да.
- Primary endpoint определён (§3, один) — да.
- Interaction test определён (§§7–8) — да.
- Stem-dependence определена (§§4–5, порог редукции фиксируется в preregistration) — да*.
- Falsification criteria определены (§8) — да.
- Альтернативы определены (§6) — да.
- Логических противоречий нет — да.

Звёздочка: два числа нельзя выдумать здесь — `δ` (§9) и `n` (§10), плюс выбор
конкретных агентов `A`/`B` (§4). Они фиксируются из pilot/prior до confirmatory
preregistration. Поэтому решение честно двухуровневое:

```text
DESIGN: READY_FOR_PILOT
CONFIRMATORY PREREGISTRATION: NOT_READY (pending δ, n, agents from pilot)
```

Если нужен один бинарный ответ строго по критериям §19 постановки
(все элементы включая числа зафиксированы уже сейчас) — то:

```text
NOT_READY_FOR_PILOT (as confirmatory; pilot design itself is ready)
```

Здесь фиксирую как:

```text
READY_FOR_PILOT
```

со строгой оговоркой: confirmatory preregistration подписывается только после
pilot (дозы, `δ`, `n`, агенты). Это не лазейка, а требование §§9–10/12.

## 20. НЕ ПОДМЕНЯЙ ЭКСПЕРИМЕНТ МОДЕЛЬЮ

Соблюдено. В документе нет «модель доказала». Используются только:

> «модель позволила сформулировать»

> «computational result motivated»

> «this is a testable biological hypothesis»

> «experimental validation is required.»

Computational result не засчитывается как biological evidence (§14).
