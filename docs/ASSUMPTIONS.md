# ASSUMPTIONS.md — Допущения проекта

Этот документ фиксирует **все принятые допущения** (`ASP` по классификации
`docs/RESEARCH.md`), чтобы их можно было оспорить, пересмотреть и проверить.
Новое допущение добавляется сюда **до** попадания в код.

## 1. Допущения о данных

| # | Допущение | Обоснование/риск |
|---|---|---|
| A-1 | Прямые подсчёты ранних стадий (in vitro, IVF/EKO) репрезентативны для in vivo развития | Риск систематического сдвига из-за культуры; in vivo не измерено |
| A-2 | Оценка клеток новорождённого 1.25×10¹² (Osgood 1955) применима как модельная точка | Косвенный массовый расчёт, 1955 г.; грубо |
| A-3 | Взрослый диапазон 3–3.7×10¹³ (Bianconi/Sender/Hatton) — рабочая точка для adult | Компиляции; пол и масса варьируют |
| A-4 | Данные животных моделей (при необходимости) экстраполируются на человека | Порядковая экстраполяция; высокая неопределённость |
| A-5 | Тотальные подсчёты пост-имплантационного и фетального периодов недоступны → не фиксируются | Не вводим необоснованные числа |

## 2. Допущения о биологии

| # | Допущение | Следствие |
|---|---|---|
| B-1 | Раннее дробление асинхронно; длительность цикла ~10–12 ч на деление | Модель использует стохастические циклы, а не синхронное 1→2→4→8 |
| B-2 | Линейная модель клетки отделяет состояние (cycle/DNA/telomere/senescence) от ткани | Первая версия — клеточный уровень без 3D ткани |
| B-3 | Сенесцентная клетка не делится; мёртвая не участвует | Инварианты для тестов |
| B-4 | Дочерние клетки наследуют стохастически модифицированное состояние родителя | Определение правил наследования теломер/повреждений |
| B-5 | Каждая клетка имеет единственную lineage и уникальный id | Инвариант lineage для тестов |
| B-6 | Среднее время деления одно и то же на каждом делении всего окна (нет EGA-программы, нет замедления клеточного цикла) | Проверено в Этапе 3: приводит к MODEL MISMATCH раннего развития (см. `docs/CALIBRATION.md`), принят сознательно как честная минимальная модель |
| B-7 | В модели нет компактизации, кавитации, TE/ICM-дифференцировки и пространства | Морула/бластоциста в анализе — только счёт+время-эвристика; `mortality.rate` однороден по всем делениям |

## 3. Допущения о численности и неопределённости

| # | Допущение |
|---|---|
| C-1 | Для параметров моделей используются центральные оценки с диапазонами (min/max), а не точечные значения как истина |
| C-2 | Минимально достаточная модель важнее полноты: сначала теломеры/ДНК-повреждения/сенесценция, остальное позже |
| C-3 | Калибровочными точками первых тестов являются: 1→2→4→8→морула~30→бластоциста 60/84/126→1.25e12 (рождение)→3–3.7e13 (взрослый) |

## 4. Допущения о вычислительной модели

| # | Допущение |
|---|---|
| D-1 | Reference-реализация: приоритет correct/reproducible/testable > скорость |
| D-2 | Одинаковый seed + одинаковое состояние RNG ⇒ воспроизводимый результат (включая checkpoint/restore) |
| D-3 | Научная модель и GUI разделены; данные публикаций не вшиты в код симулятора |
| D-4 | Модель версиируется; результаты хранят версию модели и версию набора данных |
| D-5 | Симуляция — вычисл. эксперимент, не медицинская рекомендация |

## 5. Процедура изменения допущений

1. Изменение записывается здесь с датой и мотивацией.
2. Если изменение влияет на результаты прошлых симуляций, в `experiments/` делается
   запись о несовместимости версий.
3. Допущение, опровергнутое новыми данными, **не удаляется**, а помечается статусом
   `superseded` + ссылка на замену.
