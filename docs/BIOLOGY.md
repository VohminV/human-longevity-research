# BIOLOGY.md — Биологическая основа модели

Этот документ описывает биологические факты, на которых строится клеточная модель,
и то, как они переводятся в вычислительную форму. Здесь нет готового кода — только
**биологическая спецификация** для `docs/ARCHITECTURE.md`.

## 1. Клеточный цикл

Соматическая клетка млекопитающего проходит фазы:

```
G0 — покой (не делится, метаболически активна)
G1 — подготовка к синтезу ДНК
S  — синтез ДНК (репликация генома)
G2 — подготовка к делению
M  — митоз (разделение ядра и цитоплазмы)
```

Важные для модели факты:

- Вход в фазы контролируется чекпойнтами (G1/S, G2/M, метафазный). При повреждении ДНК
  клетка может **остановиться** в G1/S или G2/M (DNA damage checkpoint).
- Не все клетки непрерывно делятся: большая часть взрослого организма находится в G0.
- Длительность цикла сильно различается по типам клеток (часы у эмбриональных → месяцы/годы
  у взрослых медленных линий).
- Дробление эмбриона на ранних стадиях — короткие циклы без заметного роста клеток.

## 2. Деление (M)

Противопоставление для модели:

```
parent cell
    ↓
daughter A   ←  inherits parent state (с мутациями/повреждениями)
daughter B
```

Требования к симуляции:

- уникальный `id` у каждой клетки;
- сохраняется `parent_id`, `generation`, `lineage_id`;
- одинаковый seed → воспроизводимый результат;
- дочерние клетки наследуют стохастически модифицированное состояние родителя
  (телемеры, повреждения ДНК, эпигенетические маркеры).

## 3. Смерть (D)

Клеточный статус не должен быть бинарным «жив/мёртв». Разделяются:

| Статус | Смысл |
|---|---|
| `normal` | жизнеспособна, может делиться |
| `senescent` | жива, но не делится (клеточное старение) |
| `apoptotic` | в процессе программируемой гибели |
| `dead` | не участвует в дальнейшем поведении |

Правила:

- сенесцентная клетка **не** продолжает обычное деление;
- мёртвая клетка **не** участвует в клеточном поведении;
- гибель может быть апоптотической, некротической или элиминирующей (фагоцитоз).

## 4. Дифференцировка и линии

Развитие — не просто «деление до N клеток»:

- деления **асинхронны** (не 1→2→4→8→16 строго одновременно);
- присутствуют **дифференцировка**, **гибель клеток**, **спецификация линий**,
  **миграция**;
- начиная с бластоцисты появляются зародышевые и внезародышевые ткани:

```
zona pellucida
  ↓ hatches
lаte blastocyst (day 5-7)
  ├── inner cell mass (ICM)
  │     ├── epiblast (EPI)     → embryo proper
  │     └── primitive endoderm (PrE) → yolk sac
  └── trophectoderm (TE)       → placenta/trophoblast
```

Из-за этого **нельзя** моделировать раннее развитие как идеализированную двоичную схему.

## 5. Хронология раннего развития человека

Ссылки на источники и доверие — в `docs/CELL_COUNT.md`. Здесь — биологическая схема
(времени от оплодотворения):

| Стадия | Время | Отличительные признаки |
|---|---|---|
| Зигота (pronuclear) | 0–1 день | два пронуклеуса |
| Дробление | дни 1–3 | 2 → 4 → 8 клеток |
| ZGA (активация зиготического генома) | ~4–8 клеток | начало эмбриональной транскрипции |
| Морула | ~день 4 | компактизация, ~10–32 клетки |
| Ранняя бластоциста | ~день 5 | полость (blastocoel), ~20–60 клеток |
| Поздняя бластоциста | ~день 5–7 | ~60–200 клеток; стр.: ICM vs TE |
| Хетчинг | ~день 5–6 | выход из zona pellucida |
| Имплантация | ~день 6–7 | начало внедрения в эндометрий |
| Гаструляция | ~день 14–19 | три зародышевых листка |

Ключевой механизм для ранней динамики — **активация эмбрионального генома
(ZGA/EGA)**: дробление — «редуктивные» деления до включения транскрипции
эмбриона, мажорный переход завершается к 8-клеточной стадии (S-19, S-20),
после чего клеточный цикл удлиняется. В модели это учитывается опциональной
группой `cell_cycle.phases` (стадия-зависимая длительность цикла и гибель при
делении; см. `docs/DEVELOPMENTAL_DYNAMICS.md`).

## 6. Что необходимо моделировать на клеточном уровне (концептуально)

Минимальный набор полей клетки (реализация — позже, см. ARCHITECTURE.md):

```
id
parent_id
generation
lineage_id
cell_type
differentiation_state
position
age
cell_cycle_state          (G0/G1/S/G2/M)
telomere_state
dna_damage
dna_repair_capacity
mutation_state
metabolic_state
senescence_state
apoptosis_state
environmental_state
```

Вводить поля нужно минимально достаточным набором, а не все сразу.

## 7. Биологические процессы, важные для будущих этапов

(Полный разбор механизмов старения — в `docs/CELLULAR_AGING.md`.)

- повреждение ДНК и накопление мутаций;
- динамика теломер;
- клеточное старение (senescence);
- истощение стволовых клеток;
- митохондриальная дисфункция;
- нарушения протеостаза;
- эпигенетические изменения;
- хроническое воспаление;
- изменения внеклеточного матрикса;
- старение иммунной системы;
- потеря регенеративной способности;
- дисфункция органов;
- риск рака.

Каждый процесс вводится в модель только по процедуре из `docs/RESEARCH.md` (evidence →
abstraction → parameters → validation → limitations).

## 8. Явно НЕ моделируется на этом этапе

- полноценный организм;
- модель старения;
- модель бессмертия;
- клинические рекомендации.
