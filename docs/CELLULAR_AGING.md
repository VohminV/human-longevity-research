# CELLULAR_AGING.md — Потенциальные механизмы старения и их моделируемость

Этот документ перечисляет **потенциальные** механизмы старения, которые проект
рассматривает как кандидатов для будущих версий модели. Пока это **каталог**, а не
реализация.

> Правило: каждый механизм попадает в код только после определения biological evidence,
> mathematical abstraction, model parameters, validation strategy, limitations
> (см. `docs/RESEARCH.md` п.4).

## 1. Потенциальные механизмы (каталог)

| # | Механизм | Одно-строчная суть | Данные для параметризации |
|---|---|---|---|
| 1 | DNA damage | накопление повреждений ДНК в геноме с возрастом | есть (обзорно); зависимость от типа клеток |
| 2 | Mutation accumulation | фиксация соматических мутаций в стволовых и соматических клетках | есть (секвенирование тканей, например кроветворение) |
| 3 | Telomere dynamics | укорочение теломер на каждое деление → лимит Hayflick | хорошо количественно изучено in vitro |
| 4 | Cellular senescence | накопление неделящихся клеток, секреторный фенотип (SASP) | есть; динамика популяций изучена частично |
| 5 | Stem cell exhaustion | истощение пулов стволовых клеток | зависимость от ткани; частичные данные |
| 6 | Mitochondrial dysfunction | падение функции митохондрий, окислительный стресс | частично; механизм спорен |
| 7 | Proteostasis | нарушение процессов укладки/деградации белков | есть in vitro; системно слабо |
| 8 | Epigenetic alterations | сдвиги метилирования/хроматина (эпигенетический «часы») | есть данные; причинность не доказана |
| 9 | Chronic inflammation | «inflammaging», системное слабоострое воспаление | есть корреляционные данные |
| 10 | ECM changes | деградация внеклеточного матрикса, потеря эластичности | есть; ткани-специфично |
| 11 | Immune aging | снижение адаптивного/врождённого иммунитета | есть; система сложная |
| 12 | Loss of regenerative capacity | падение регенерации тканей | связано с #5,#4 |
| 13 | Organ dysfunction | потеря функции органов (сердце, почки, лёгкие, ГЭБ…) | есть клинические данные |
| 14 | Cancer risk | рост риска злокачественных образований с возрастом | есть статистические данные |

## 2. Главный принцип: старение ≠ `age += 1`

В модели старение **должно быть эмерджентным результатом** взаимодействия нескольких
процессов (повреждение ДНК, укорочение теломер, сенесценция, истощение стволовых клеток
и т.д.), а не принудительным инкрементом возраста.

Примерная схема связей (концептуальная, не финальная):

```
DNA damage ──► снижение пролиферации ──► потеря функций ткани
                                          ▲
telomere shortening ──► replicative senescence
                                          │
senescent cells ──► SASP ──► inflammation ─┘
                              │
stem cells ──► exhaustion
```

Такая схема позволит отличать «молодые» вмешательства (например, усиление репарации
ДНК) по влиянию на **эмерджентные** метрики.

## 3. Для каждого механизма — статус моделируемости (черновик)

| # | Механизм | Моделируемо сейчас? | Почему |
|---|---|---|---|
| 3 | Telomere dynamics | **Да, абстрактно** | хорошо изучено; равно-деление/неравно-деление (stem/non-stem) описано численно |
| 1 | DNA damage | **Частично** | повреждения можно поле-лечить как стохастический процесс с репарацией; параметры грубые |
| 4 | Cellular senescence | **Частично** | популяционная динамика моделируется; SASP-влияние сложно |
| 2 | Mutation accumulation | Частично | в модели клетки — «mutation_state», частоты мутаций доступны |
| 5 | Stem cell exhaustion | Частично | требует модели «пулов» стволовых клеток |
| 6–14 | Остальные | Пока нет | недостаточно однозначных количественных моделей для reference-реализации; вводить поэтапно |

## 4. Метрики (для будущих экспериментов)

Биологическое состояние не сводится к одному числу. По мере появления модели измеряются:

```
cell count
living cells
dead cells
senescent cells
cell division rate
lineage depth
DNA damage
mutation burden
telomere state
stem-cell reserve
regenerative capacity
inflammation
organ function
biological age
healthspan
lifespan
```

Ни один параметр не является достаточным показателем состояния организма.

## 5. Открытые исследовательские вопросы для гипотез

1. Какой из механизмов «ведёт» деградацию в модели с минимальным набором процессов?
2. Какие вмешательства (параметрические изменения) дают наибольший прирост healthspan?
3. Существуют ли конфигурации, при которых система остаётся функциональной
   неограниченно долго (и что при этом ломается первым)?
4. Как влияет «цена» деления (теломеры, повреждения, эпигенетика) на популяционную
   динамику?

Эти вопросы формулируются как `HYP` и проверяются только после появления симуляции.
Список гипотез ведётся в `research/hypotheses/`.
