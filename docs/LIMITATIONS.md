# LIMITATIONS.md — Ограничения данных, модели и интерпретаций

Для научной честности проект фиксирует, чего он **не** знает и **не** умеет.
Ниже — текущий реестр ограничений. Он растёт вместе с моделью.

## 1. Ограничения данных

| # | Ограничение | Влияние |
|---|---|---|
| L-1 | Нет прямых подсчётов клеток человека для имплантации, пост-имплантации и фетального периода | Количества для этих периодов не фиксируются как факт |
| L-2 | Прямые подсчёты ранних стадий — только in vitro (IVF), выборки десятков эмбрионов | Возможен систематический сдвиг; низкая статистика |
| L-3 | scRNA-seq данные — захваченные клетки, не тотальные счёты | Нельзя выводить общую численность из захваченных клеток |
| L-4 | Оценки взрослого и новорождённого варьируют на ~20–30% между работами | Опора на диапазон, а не на единственное число |
| L-5 | Межвидовые экстраполяции (если используются) грубые | Порядковое, не точное |

## 2. Ограничения модели

| # | Ограничение |
|---|---|
| M-1 | Первая реализация — клеточный уровень без пространственной 3D-ткани, без обмена веществ, без физики |
| M-2 | Только подмножество механизмов старения (претенденты: теломеры, ДНК-повреждения, сенесценция) |
| M-3 | Параметры отдельных механизмов неизвестны или грубы → входные распределения с широкими диапазонами |
| M-4 | Эмерджентность модели ограничена выбранным набором процессов; отсутствующие процессы могут быть главными ограничителями |
| M-5 | Отсутствуют системные/организменные связи (эндокринология, иммунитет, нейрофизиология) |
| M-6 | Нет плато роста: при постоянном времени деления и отсутствии смерти рост экспонентен; Этап 3 зафиксировал расхождение с бластоцистой на 1–3 порядка (см. `docs/CALIBRATION.md`) |
| M-7 | Нет компактизации/кавитации, клеточных судеб TE/ICM, эмбриональной активации генома; нет стадия-зависимой гибели |

## 3. Ограничения интерпретации

| # | Ограничение |
|---|---|
| I-1 | Результаты симуляции — **предсказания в рамках модели**, не биологические факты |
| I-2 | «Иммортальность» в модели ≠ подтверждённый биологический результат |
| I-3 | Выводы об aging из модели требуют валидации против литературы и, в перспективе, экспериментов |
| I-4 | Никакие выходы не являются медицинскими рекомендациями |

## 4. Открытые вопросы, дающие неопределённость

1. Реальна ли скорость клеточного цикла раннего эмбриона in vivo?
2. Сколько делений фактически происходит от зиготы до взрослого (с учётом гибели)?
3. Пространственная организация и межклеточная сигнализация — до какой стадии
   развития они критичны для счёта клеток?
4. Какие механизмы старения являются причинными, а какие коррелятами?

## 5. Процедура фиксации ограничений

- Ограничение добавляется с датой и, при необходимости, с предложением, как его
  снять (документация, источник данных, будущая работа).
- Ограничения, снятые новыми данными, помечаются `resolved` и переносятся в отдельный
  раздел с указанием, что именно изменилось.
