# RESEARCH.md — Научный контекст и методология

Этот документ фиксирует, как проект отделяет **наблюдение** от **инференции**,
**допущения** и **гипотезы**. Это граница, которая не должна размываться: ошибки в этой
границе превращают научную модель в вымысел.

## 1. Цель

Проект — вычислительная исследовательская платформа. Её компоненты:

1. **SCIENTIFIC DATA** — количественные данные из опубликованных исследований.
2. **BIOLOGICAL MODEL** — математическая абстракция биологических процессов.
3. **SIMULATION ENGINE** — исполнение модели на дискретных клеточных популяциях.
4. **EXPERIMENT ENGINE** — контролируемые вычислительные эксперименты.
5. **LONGEVITY ANALYSIS** — интерпретация результатов (lifespan, healthspan, …).

Платформа позволяет формулировать и проверять *гипотезы о механизмах*, но сама по себе
не производит новых биологических фактов. Симуляция — источник **предсказаний**, которые
потенциально проверяемы в реальных экспериментах.

## 2. Категории знания

Каждый количественный параметр в проекте должен быть отнесён к одной из категорий:

| Категория | Обозначение | Значение |
|---|---|---|
| **Observation** | `OBS` | Измерено прямым экспериментом. Например: диапазон X получен из данных. |
| **Inference** | `INF` | Выведено из наблюдений косвенно, с предположениями о связях. |
| **Assumption** | `ASP` | Принято без прямого подтверждения, явно отмечено как допущение. |
| **Model choice** | `MOD` | Параметр/распределение, которым симулятор заменяет неполные данные. |
| **Hypothesis** | `HYP` | Проверяемое утверждение о механизме. Не является фактом. |

Пример из `docs/CELL_COUNT.md`:

```
OBS:  прямым подсчётом ядер получено 58.3 ± 8.1 клеток в бластоцисте на день 5 (in vitro).
INF:  in vivo бластоциста на день 5 содержит сопоставимое число клеток.
ASP:  культура in vitro не сдвигает систематически число клеток.
MOD:  симулятор использует логнормальное распределение со средним ≈ 60 (день 5).
HYP:  увеличение пролиферации трофэктодермы на день 5 повышает имплантационный потенциал.
```

## 3. Правила использования количественных данных

1. Для важных параметров используются **peer-reviewed источники** (PubMed, Nature, Cell,
   Science, eLife и т.п.). Случайные сайты не являются основанием.
2. Для каждого ключевого параметра записываются: **source, DOI, PMID, год, метод
   измерения, выборка, неопределённость, примечания**.
3. Если источники расходятся — **не выбирается одно число молча**. Сохраняются
   minimum / maximum / central estimate / source / причина расхождения.
4. Метод измерения определяет доверие к числу:
   - прямое считывание (direct count);
   - взвешивание/объёмное вычисление (mass/volume-based estimate);
   - экстраполяция от другой стадии или вида (extrapolation);
   - вычислительный вывод (computed).
5. Числа из single-cell sequencing — это **захваченные для секвенирования клетки**,
   а не общая численность клеток органа или стадии. Эти величины не подменяют друг друга.

## 4. Процесс введения механизма в модель

Новый механизм (например, клеточное старение) вводится только после определения:

1. **biological evidence** — какие наблюдения его поддерживают;
2. **mathematical abstraction** — в какой форме он попадёт в код;
3. **model parameters** — откуда взяты параметры и какая у них неопределённость;
4. **validation strategy** — как проверить, что абстракция не искажает биологию;
5. **limitations** — что эта абстракция не покрывает.
