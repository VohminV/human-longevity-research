## 1. HYP-2 — точная формулировка (смысл зафиксирован, не закон)

> Повышение регенеративной ёмкости старой ткани сопровождается ростом онкологической
> нагрузки вдоль устойчивого фронта «регенерация–рак»; выход за фронт (лучшая
> регенерация при не большей опухолевой нагрузке) без отдельного механизма
> онкоконтроля не наблюдается.

Уточнения, входящие в формулировку:

- это гипотеза, не установленный закон;
- один валидный контрпример фальсифицирует универсальную формулировку;
- frontier является empirical frontier в заранее определённом experimental space.

## 2. Research question — два отдельных вопроса

- **Вопрос A (структура):** есть ли в заранее определённых reference arms достаточная
  структура `(R, N)`, чтобы построить информативный эмпирический фронт?
- **Вопрос B (классификация):** где находится заранее выбранный test arm относительно
  заранее построенного фронта?
- Вопрос A — статистический тест структуры; вопрос B — классификация по правилу §14.
  Итоговые ярлыки только: `supports / compatible / classified as / indistinguishable /
  falsifies`. Формулировка «H1 принимается» запрещена.

## 3. H0

Данные совместимы с отсутствием тестируемого фронта: reference arms не дают
информативной структуры (вырожденный фронт / полоса шире максимума), либо положение
test arm относительно фронта неразличимо. H0 — отсутствие основания для вывода,
а не «доказательство отсутствия tradeoff».

## 4. H1 (без слова «принимается»)

Положение test arm классифицируется как `frontier-consistent` (на/внутри фронтовой
полосы с учётом совместной неопределённости) при информативном фронте из вопроса A.

## 5. Что считается tradeoff

Существование пред-определённой Pareto-efficient boundary в пространстве
`R = regenerative capacity` (максимизировать) × `N = neoplasia burden`
(минимизировать), оценённой внутри заранее определённого экспериментального
пространства. Строгая попарная монотонность всех точек не требуется.
Простая корреляция `R–N` tradeoff не считается (корреляция ≠ структура границы).

## 6. Фронт: empirical Pareto-efficient boundary (геометрия зафиксирована)

Фронт = `empirical Pareto-efficient boundary` достижимых `(R, N)`-точек
референсных плеч (контроль + моно-плечи) с полосой совместной неопределённости.
`R → maximize`. `N → minimize`. Не используются формулировки:
`upper envelope`, `global Pareto frontier`, `fundamental frontier`,
`universal biological frontier`.
Этот фронт оценивает **только** заранее определённое экспериментальное пространство.
Он НЕ оценивает недоступные вмешательства, НЕ доказывает глобальный биологический
Pareto-frontier, НЕ доказывает универсальный закон старения.

## 7. Построение фронта без подгонки

Фронт строится из референсных плеч **того же** эксперимента (исторические данные
запрещены — batch-конфаунд). До раскрытия test arm фиксируются: множество
референсных плеч, способ оценки границы, способ построения полосы, максимум
ширины полосы. Тестовая точка классифицируется один раз. Перестроение фронта
после просмотра тестовой точки запрещено и фиксируется как нарушение протокола.

## 8. Primary estimand (строго двумерный, без composite score)

`position of the test arm relative to the empirical Pareto boundary
in the predefined (R,N) space` с двумя компонентами: `deviation in R`,
`deviation in N`. Composite score запрещён. Категории:
1. `frontier-consistent`;
2. `frontier-exceeding in the favourable direction`;
3. `indeterminate`.
Пороги, если неизвестны, — `UNKNOWN`, фиксируются до confirmatory experiment.

## 9. Primary endpoints (два ко-первичных)

- `R`: регенеративная морфометрия + функциональный readout (по классу вмешательства).
- `N`: опухолевая нагрузка — макроскопия + обязательная слепая гистология
  пред-зафиксированной панели. Без чувствительной `N`-оси тест несостоятелен.

## 10. Вторичные endpoints

Механистические маркеры осей, `MuSC`-пул/активация, воспаление, масса/корм,
безопасность. Только интерпретация и альтернативы; повышение до primary запрещено.

## 11. Unit of analysis: animal (включая редкие N-события)

Основная единица — `animal`. Автоматический переход `animal → cohort`
только из-за редкости опухолей запрещён. Для редких событий заранее выбирается
animal-level statistical framework (бинарный исход, `time-to-event` или иная
заранее специфицированная модель). Конкретный метод:
`UNKNOWN → fixed before confirmatory analysis`.
Клетки/волокна не являются независимыми biological replicates (pseudoreplication
запрещён; только animal-level сводки или иерархическая модель, выбор — до данных).

## 12. Отдельный механизм онкоконтроля (операционное определение)

`separate cancer-control mechanism` = заранее заявленный механизм/вмешательство,
основной целью которого является снижение неопластической нагрузки и который
концептуально отделён от механизма повышения регенеративной ёмкости.
Требования: критерии заявляются ДО анализа результатов; post-hoc объявление
регенеративного вмешательства «отдельным онкоконтролем» запрещено; изменение
определения после результата запрещено; использование cancer-control как
спасательной лазейки запрещено. Если у тестируемого вмешательства заранее известен
самостоятельный противоопухолевый механизм — это указывается до эксперимента.
Первый чистый тест предпочтительно на классе без заявленного онкоконтроля.
Двойное действие — заранее классифицированный отдельный сценарий.
Конкретные препараты/дозы не выдумываются.

## 13. Различение исходов

- **A — обычное улучшение регенерации** (без информативной `N`-оси): не тест HYP-2,
  результат неинформативен.
- **B — tradeoff** (точка на фронте): совместимо с HYP-2 — формулировка только
  `compatible with HYP-2 within the tested experimental space`, никогда
  «доказательство HYP-2».
- **C — независимое улучшение обеих осей** (вне полосы в «хорошую» сторону):
  фальсификация в tested class.
- **D — ухудшение обеих**: токсичность/неудачный класс — редизайн, не вывод.
- **E — эффект только в одном классе**: не переносится на общую версию без Stage B
  (второй класс + правило выбора — до раскрытия Stage A; выбирать удобный класс
  после Stage A запрещено; Stage B — только replication, cross-class
  generalizability, transferability).

## 14. Критерий фальсификации (жёсткий)

Поддержка в классе — конъюнкция: информативный фронт (вопрос A пройден);
точка `frontier-consistent`; `N`-ось чувствительна; анализ animal-level.
Фальсификация в классе: валидная точка категории 2
(`frontier-exceeding in the favourable direction`) при выполненных условиях
информативности. Постфактум запрещены: перестройка фронта, смена методов/`R`/`N`/
горизонта/класса, добавление/удаление плеч, объявление онкоконтроля, исключения
по исходу, ярлык «аномалия». Репликация — отдельная заранее зарегистрированная
стадия, не отмена результата.
`p > 0.05` = `failure to detect`, не доказательство; значимость сама по себе
не фальсификация; решает положение vs фронт. Частичное перекрытие области точки
с полосой = `indeterminate`. Одна ось улучшилась, вторая неопределённа =
`indeterminate`, не поддержка.

## 15. Универсальная логика (четыре правила, других нет)

- Валидный контрпример в Stage A → универсальная HYP-2 фальсифицирована:
  `HYP-2 falsified for the stated universal formulation.` Stage B для этого НЕ нужен.
- Совместимость в Stage A → не доказательство универсальности.
- Совместимость и в Stage B → дополнительная репликация/cross-class evidence.
- Нарушение в Stage B → дополнительный counterexample, универсальная версия
  также не сохраняется.

## 16. Класс вмешательства (пред-фиксация, без привилегий)

Кандидаты: `partial reprogramming`, `stem-cell mobilisation`,
`mTOR/autophagy-related intervention` и т.п. Конкретный класс —
`pre-specified before confirmatory data collection`; постфактум-выбор запрещён.
HYP-1-связка не привилегирована и не запрещена — один из кандидатов на общих
основаниях.

## 17. Горизонт, включение/исключение, рандомизация, confounders

Горизонт — до данных (латентность опухолей + кинетика регенерации + pilot);
продление после просмотра запрещено. Критерии включения/исключения — списком
до данных, слепо к группе; удаление по исходу запрещено. Рандомизация в плечи
(стратификация), ослепление оценки `R` и обязательно `N`-гистологии, раскрытие
после фиксации датасета.

| Confounder | Контроль |
|---|---|
| body mass / food intake | взвешивание, учёт корма; при сдвиге — `pair-feeding`/ковариата |
| sex, age | стратификация; фиксированный диапазон до данных |
| injury severity, batch | стандартизованная травма; batch как strata/covariate |
| circadian effects, treatment timing | фиксированное время; прайминг vs одновременность — до данных |
| toxicity/tolerability, потери | мониторинг, humane endpoints, пред-правила учёта потерь |
| MuSC-независимые пути улучшения `R` | доля de novo волокон, `Pax7`-линия (по классу) |

## 18. NO-GO эксперимента и расширения

NO-GO эксперимента (тест не способен дать интерпретируемый результат, а не
«результат не понравился»): нечувствительная `N`-ось; вырожденный фронт;
полоса шире максимума; невозможна слепая гистология; чрезмерная токсичность;
нет `R`-сепарации. NO-GO расширения: Stage A неопределён; фронт вырожден;
классы не независимы; правило переноса не зафиксировано до Stage A.

## 19. Интерпретация относительно HYP-0

Фронт воспроизводится в независимых классах → биологическое свидетельство
устойчивой структуры tradeoff, совместимой со структурной интерпретацией
остаточного ограничения HYP-0 (не «найденный фундаментальный предел»).
Фронт нарушен → контрпример механизму-ограничителю, интерпретация HYP-0
пересматривается. В обоих исходах HYP-0 остаётся `hypothesis_not_proven`.

## 20. Чего результат НЕ означает

Не бессмертие и не его невозможность; не невозможность омоложения;
не универсальный закон старения; не глобальный Pareto-frontier;
не фундаментальный математический предел регенерации;
не предел всех rejuvenation interventions.

## 21. Adversarial literature (сохранена, не доказательство)

- Антагонистическая плейотропия (`p53`/сенесценция) — `PMID 18639575`,
  `PMCID PMC6276058`: фон tradeoff, не доказательство HYP-2.
- Онкогенность Yamanaka и необходимость таргетности — `PMC10861195`:
  предостережение, не доказательство.
- Таргетный `Cdkn2a-OSK` без роста опухолей в описанном эксперименте —
  `PMID 39259812`: важный adversarial precedent (отсутствие роста опухолей
  при регенеративном эффекте эмпирически правдоподобно), но НЕ автоматическая
  фальсификация HYP-2, поскольку это не зарегистрированный `R/N` frontier experiment.
  Вывод из него: HYP-2 нельзя принимать как установленный tradeoff.
- `Trametinib + rapamycin`: аддитивность + снижение части опухолевых исходов —
  `DOI 10.1038/s43587-025-00876-4` / `PMID 40437307`: ни доказательство HYP-2,
  ни её опровержение без `R/N` frontier design.
- `NR` + нагрузка (`PMID 35998039`): target engagement не гарантирует
  функционального регенеративного эффекта.

## 22. Уровни вывода (на каждое существенное утверждение)

- KNOWN: антагонистическая плейотропия; онкогенность Yamanaka.
- SUPPORTED: аддитивность комбинаций как фон; `Cdkn2a-OSK`-прецедент как основание
  не принимать tradeoff как установленный.
- UNTESTED: положение фронта для конкретных классов; горизонт информативности
  `N`-оси; переносимость между классами.
- MODEL-GENERATED: `рак ×3.3`, residual-динамика, resource constraints, `v1–v6`,
  robustness, slope, computational frontier. These results are properties of the
  project’s computational model and are not direct evidence of the corresponding
  biological mechanism. Модельные числа на животных/человека не переносятся.

## 23. Причинная цепочка (проверка)

`HYP-0` → computational residual → отсутствие биологического доказательства →
HYP-2 как независимая гипотеза → литературная plausibility → эмпирический
frontier-эксперимент → `support / falsification / indeterminate`.
Формулировки `model → biological law` нет.

## 24. Граница preregistration (что фиксирует pilot)

Доза (обе), `δ`-аналог для фронта, `sample size` (из variance + мощность
joint-процедуры), timing, мощность, финальные исключения, метод joint
uncertainty, `N`-панель и горизонт. После фиксации post-hoc изменение
под результат запрещено.

## 25. Двухступенчатая структура (без computational-сущностей)

- **Stage A (class-specific test):** один пред-выбранный класс; проверяет tradeoff
  и измеримость фронта. Валидный контрпример фальсифицирует универсальную HYP-2
  (с сужением/отказом).
- **Stage B (cross-class replication):** только если Stage A информативен и второй
  класс выбран до результата Stage A из независимого механизма; проверяет
  переносимость и репликацию, а не «дофальсифицирует».
